Reassembles and sign-\/extends the 13-\/bit branch offset. 

The B-\/format immediate is scattered across four disjoint ranges and omits bit 0, which is implicitly zero (offsets are 2-\/byte aligned):

{\ttfamily \+[31]}  &{\ttfamily \+[12]}  \\
{\ttfamily \+[7]}  &{\ttfamily \+[11]}  \\
{\ttfamily \+[30:25]}  &{\ttfamily \+[10:5]}  \\
{\ttfamily \+[11:8]}  &{\ttfamily \+[4:1]}  \\
\end{DoxyTable}


\begin{DoxyReturn}{Returns}
The byte offset, sign-\/extended to 32 bits, in {\ttfamily \+[-\/4096, 4094]}. 
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The result is always even and is relative to the branch\textquotesingle{}s own address, not the next instruction.
