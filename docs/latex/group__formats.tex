\doxysubsection{Detailed Description}
Typed views over a raw instruction word, one per RISC-\/V encoding. 

Each type wraps the undecoded word and exposes only the fields its encoding actually defines. Field accessors delegate to \doxylink{namespace_r_v32_1_1base}{RV32::\+base}; the immediate accessors perform format-\/specific reassembly and sign extension.
