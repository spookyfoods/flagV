◆ get_imm()

int32_t BType::get_imm ( ) const
inlineconstexpr

Reassembles and sign-extends the 13-bit branch offset.

The B-format immediate is scattered across four disjoint ranges and omits bit 0, which is implicitly zero (offsets are 2-byte aligned):

Instruction bits Immediate bits
[31] [12]
[7] [11]
[30:25] [10:5]
[11:8] [4:1]
Returns
The byte offset, sign-extended to 32 bits, in [-4096, 4094].
Note
The result is always even and is relative to the branch's own address, not the next instruction.
