int32_t UType::get_imm ( ) const
inlineconstexpr

Extracts the upper 20-bit immediate field and shifts it into standard 32-bit format. In U-Type instructions (e.g., LUI, AUIPC), the immediate forms the upper 20 bits of a 32-bit value, with the lower 12 bits set to zero.

Instruction's bits Immediate bits
[31:12] [31:12]
Returns
32-Bit Signed Integer
Note
The returned value is shifted left by 12 bits (imm << 12), making it consumption-ready for instruction execution, but it is not in its raw, unshifted (numerically accurate 20-bit) value.
