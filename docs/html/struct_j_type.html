int32_t JType::get_imm ( ) const
inlineconstexpr

Reassembles and sign-extends the 21-bit jump offset.

The J-format immediate is scattered across four disjoint ranges and omits bit 0, which is implicitly zero (offsets are 2-byte aligned):

Instruction bits Immediate bits
[31] [20]
[19:12] [19:12]
[20] [11]
[30:21] [10:1]
Returns
The byte offset, sign-extended to 32 bits.
Note
The result is always even and is relative to the jump's own address, not the next instruction.
