Detailed Description

Typed views over a raw instruction word, one per RISC-V encoding.

Each type wraps the undecoded word and exposes only the fields its encoding actually defines. Field accessors delegate to RV32::base; the immediate accessors perform format-specific reassembly and sign extension.
